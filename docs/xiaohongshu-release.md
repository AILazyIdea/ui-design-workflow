# 小红书发布素材与边界

## 可用标题

我把截图到 UI 评审做成了一套本地 Agent 工作流

## 正文骨架

这不是一个“让 AI 自动设计”的工具。它把我做 UI 时最容易失控的部分拆开了：先把截图或需求整理成版本化规格，再生成、截图、评审，最后用门禁确认还有没有阻塞问题。

它不绑定 DeepSeek Harness，也不保存 API Key。DeepSeek、Codex、Claude 这类工具能否直接接入，取决于它们是否支持对应的 Skill/MCP 配置；仓库会把已验证和实验性适配分开写清楚。

我先开源的是本地版：核心不用装 npm 包，增强截图和图像差异对比按需安装。适合想把“看起来差不多”变成可复查流程的人。

## 发布前检查

- 截图只用自制演示页，遮掉用户名、公司名、内部 URL、浏览器标签、路径和密钥。
- 不写“像素级”“所有 Agent 通用”“自动设计”这类无法验证的承诺。
- 以仓库主页、版本号和可复现命令为准；平台内链、外链和商业合作规则以发布当日客户端提示为准。
- 不在图中展示任何 API Key、私有工作流、客户设计稿或未授权品牌素材。
